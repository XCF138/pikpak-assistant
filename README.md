# PikPak 助手（油猴脚本）

PikPak 网页助手：一个 Tampermonkey 油猴脚本，把常用的网盘整理操作集中到一个可拖动、可缩放的悬浮工作台里。直接使用网页登录状态，无需配置账号密码。

## 功能

- **📋 批量复制 / 移动**：把一个文件（或多个文件/文件夹）批量复制或移动到多个目标文件夹，支持全选/反选、按路径自动创建文件夹。
- **🗂 文件整理**：移到回收站（可恢复）、批量解压（zip/rar/7z 到所在目录）、文件查重（按哈希+大小分组，一键清理重复文件）。
- **🌳 目录树导出**：把文件夹结构导出为 TXT 或 PNG 图片，可自定义扫描深度。
- **✏️ 批量重命名**：按括号、关键字、位置（某字前/后/之间）删除或替换文字，可选加序号 `1. 2. 3.`，预览确认后执行。

## 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)。
2. 新建脚本，把 `pikpak-batch-copy.user.js` 的**全部内容**粘贴进去并保存。
3. 打开并登录 https://mypikpak.com/ ，页面右下角会出现「PikPak 助手」悬浮球。

## 使用说明

- 点击悬浮球展开工作台，顶部四个标签切换功能。
- 按住顶部标题栏可拖动窗口，右下角手柄可缩放，位置大小自动记忆。
- 所有操作都直接调用 PikPak 官方接口，复用你网页的登录态。

## 说明

- 删除操作默认走「回收站」，可恢复，不会彻底删除文件。
- 仅供个人网盘文件整理使用，请遵守 PikPak 服务条款。
