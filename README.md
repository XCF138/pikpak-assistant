# PikPak 助手（油猴脚本）

PikPak 网页助手：一个 Tampermonkey 油猴脚本，把常用的网盘整理操作集中到一个横屏、可拖动、可全屏的悬浮工作台里。直接使用网页登录状态，无需配置账号密码。

## 功能

- **📋 批量复制 / 移动**：把一个文件（或多个文件/文件夹）批量复制或移动到多个目标文件夹，支持全选/反选、按路径自动创建文件夹。
- **🗂 文件整理**：移到回收站（可恢复）、批量解压（zip/rar/7z 到所在目录）。
- **🔎 文件查重**：按「哈希+大小」分组找出重复文件，支持关键字搜索筛选，每组保留时间最新的一个、其余一键移入回收站。
- **🌳 目录树导出**：把文件夹结构导出为 TXT 或 PNG 图片，可自定义扫描深度与格式。
- **✏️ 批量重命名**：按括号、关键字、位置（某字前/后/之间）删除或替换文字，可选加序号 `1. 2. 3.`，预览确认后执行。

## 安装

### 方式一：一键安装（推荐）

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)。
2. 打开下面这个链接，Tampermonkey 会自动弹出安装确认：

   👉 https://raw.githubusercontent.com/XCF138/pikpak-assistant/main/pikpak-batch-copy.user.js

3. 打开并登录 https://mypikpak.com/ ，页面右下角会出现「PikPak 助手」悬浮球。

> 这样安装后，脚本会自动检查更新（`@updateURL` 已指向本仓库）。

### 方式二：手动安装

1. 打开 [pikpak-batch-copy.user.js](./pikpak-batch-copy.user.js)，复制全部内容。
2. Tampermonkey 里新建脚本，粘贴并保存。

## 使用说明

- 点击悬浮球展开工作台，顶部标签切换功能。
- 按住顶部标题栏可拖动窗口，右下角手柄可缩放；右上角「⛶ 全屏」可切换全屏/窗口，位置大小自动记忆。
- 所有操作都直接调用 PikPak 官方接口，复用你网页的登录态。
